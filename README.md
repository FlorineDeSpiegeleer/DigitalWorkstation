# Sirris Digital Workstation

React/Vite export van de Figma prototypewebsite.

## Lokaal testen

```bash
npm install
npm run dev
```

## GitHub Pages

1. Upload/publish deze volledige map als een nieuwe GitHub repository.
2. Ga naar Settings → Pages.
3. Kies bij Source: **GitHub Actions**.
4. Push naar `main`; de workflow publiceert automatisch de website.

De AprilTag-productcontrole is bewust nog niet geïntegreerd en kan later toegevoegd worden.
